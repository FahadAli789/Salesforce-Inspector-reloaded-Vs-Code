# Changelog

All notable changes to the "salesforce-inspector-reloaded-vscode" extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] - 2026-10-06
### Added
- Initial release of the Salesforce Inspector Reloaded VS Code extension.
- Support for Data Export, Data Import, Org Limits, and API Exploration.
- Compatible with local VS Code and cloud environments (e.g., Salesforce Code Builder).
- Uses a local proxy server to securely route requests utilizing the Salesforce CLI session.
